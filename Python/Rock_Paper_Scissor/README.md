# ✊🤚✌️ Rock Paper Scissors

The classic game played in the terminal against the computer.

**Tech:** Python 3 (standard library only)

## Features
- Choose Rock, Paper or Scissors from a numbered menu
- The computer picks at random
- Prints both choices with emoji and announces the winner or a tie

## Concepts Practised
- The `random` module
- User input and validation
- Conditional logic for the win rules

## Run Locally
```bash
python game.py
```
