# 🧮 CLI Calculator

A menu-driven calculator that runs in the terminal.

**Tech:** Python 3 (standard library only)

## Features
- Add, subtract, multiply and divide
- Loops until you choose **Exit**
- Handles division by zero without crashing
- Re-prompts on an invalid menu choice

## Concepts Practised
- Functions and `if/elif` branching
- The `operator` module (`op.add`, `op.truediv`, …)
- `try/except` error handling
- `while True` loops and `sys.exit()`

## Run Locally
```bash
python calculator.py
```
