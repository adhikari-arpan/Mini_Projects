# 🕒 World Digital Clock

A live digital clock that shows the current time in a time zone you pick from a list.

**Tech:** HTML · CSS · JavaScript (no libraries)

## Features
- Updates every second
- Time zone dropdown: Kathmandu, New York, Chicago, London, India, Sydney, Toronto, Vancouver
- Shows today's date under the clock

## Concepts Practised
- Timers with `setInterval`
- The `Date` object and `toLocaleTimeString` with the `timeZone` option (Intl API)
- Updating the DOM in real time

## Run Locally
No build step. Open `index.html` in any browser.
