# Vanilla JavaScript Projects

Small browser apps that practise DOM manipulation, events and timers, built without any frameworks.

| Project | Description |
|---------|-------------|
| [Background Colour Switcher](BGChanger_JS) | Click a swatch to change the page background |
| [BMI Calculator](BMI_Calculator) | Calculates BMI and shows the health category |
| [World Digital Clock](Digital_Clock) | Live clock with a time zone selector |
| [Number Guessing Game](Number_Guesser) | Guess the number from 1 to 100 in 10 tries |

**Run any project:** open its `index.html` in a browser. No build step is needed.
