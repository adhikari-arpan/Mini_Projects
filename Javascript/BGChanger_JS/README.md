# 🎨 Background Colour Switcher (Vanilla JS)

A one-page app that changes the page background when you click a colour swatch.

**Tech:** HTML · CSS · JavaScript (no libraries)

## Features
- Five colour swatches: red, yellow, orange, blue, pink
- The background updates the moment you click a swatch

## Concepts Practised
- Selecting elements with `querySelectorAll`
- Attaching click handlers with `forEach` + `addEventListener`
- Reading `event.target.id` and changing inline styles from JavaScript

## Run Locally
No build step. Open `index.html` in any browser.

## Files
```
BGChanger_JS/
├── index.html   # Markup and colour swatches
├── style.css    # Layout and swatch styling
└── script.js    # Click handling and background change
```
